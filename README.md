# Superstore Sales Dashboard

## Internship Task
Future Interns - Data Science & Analytics Internship

Task 1: Sales Dashboard Development

## Project Overview
This project analyzes Superstore sales data using Power BI to uncover business insights related to sales, profitability, products, and regional performance.

## Key Metrics

- Total Sales: $633K
- Total Profit: $85.8K
- Total Orders: 1K
- Average Order Value: $465.9

## Dashboard Features

- KPI Cards
- Revenue Trend Analysis
- Top Revenue Generating Products
- Profit Margin Analysis
- Profit Contribution Analysis
- Regional Performance Analysis
- Category Performance Table
- Interactive Slicers

## Key Insights

- Technology category generated the highest sales.
- West region achieved the highest revenue.
- Copiers delivered the highest profit.
- Sales grew significantly between 2015 and 2016.
- Profitability varies across categories and products.

## Tools Used

- Power BI
- Power Query
- DAX
- Data Visualization
- Data Analysis
